# Результаты измерения производительности

**Инструмент:** ApacheBench (ab)

**Флаги:**
- **`-l`** — игнорировать разницу в длине ответа (необходим для тестов с переменной длиной ответа)
- **`-c`** — количество параллельных запросов (concurrency level)
- **`-n`** — общее количество запросов (total requests)

**Пример команды:**
```bash
ab -l -c 500 -n 10000 http://localhost:8080/gunicorn/ 
```

## Выводы

1. **Статика (nginx):**
   - Высокая производительность: ~18 700 RPS при 1000 concurrent
   - Порог: 1000 concurrent
   - При увеличении на 10% (1100) появились ошибки

2. **Gunicorn через nginx:**
   - Ограничен задержкой 50 мс в приложении
   - Производительность: ~78 RPS (ограничение приложения)
   - Порог: 500 concurrent
   - При увеличении на 10% (550) соединения сбрасываются

3. **Прямой Gunicorn:**
   - Аналогичная производительность: ~78 RPS
   - Выше устойчивость к параллельным запросам (до 2000 concurrent)
   - Порог: 2000 concurrent
   - При увеличении на 10% (2200) появляются ошибки

**Общее наблюдение:** nginx успешно проксирует запросы к gunicorn, но не увеличивает пропускную способность приложения из-за искусственной задержки 50 мс. Nginx показывает отличную производительность на статике.
